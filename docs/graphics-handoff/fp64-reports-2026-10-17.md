# FP64, global atomics and report semaphores — 2026-10-17

All covered by unit/GPU tests; nothing here was seen in a game.

## FP64 (`decoder/double_arithmetic.*`, `codegen/lang/msl/intrinsics.cpp`)
- DADD, DMUL, DFMA (`5b70`/`4b70`/`3670`, plus the constant-addend form `5370`), DMNMX, DSETP and DSET in register, constant buffer and immediate forms. Encodings from envytools `gm107.c`: A/B abs and neg bits, rounding in bits 39–40 (DADD/DMUL) or 50–51 (DFMA), comparison codes 0–15, boolean op, `.BF` on DSET. `.CC` is logged and ignored.
- Metal has no doubles, so everything is soft float on `ulong`. One exact fused multiply-add (`hydra_f64_fma`, 128-bit alignment with a sticky bit, all four rounding modes, subnormals, overflow per mode, NaN/Inf/zero-sign rules) implements DFMA, DADD (`a*1.0+b`) and DMUL (`a*b+signed zero`). Compare and min/max are separate helpers.
- Exact conversions: F2I from F64 (rounding modes, saturation, 16/32/64 bit), I2F to F64 (8/16/32/64 bit sources, single rounding) and F2F.F64.F64 integer rounding. NaN gives 0 for 32/16-bit results and `0x8000…` for 64-bit ones, like the 32-bit helper.
- Tests (`testDoublePrecision`, `testDoubleConversions`): 3000 cases per rounding mode against the host's `std::fma`/`+`/`*` (special values, subnormals, near-overflow, forced cancellation), every comparison code, min/max with NaN and signed zero, and the conversions. Mutating the host rounding mode makes the test fail, so it does check the rounding.
- Not done: FP64 `.CC`, `FTZ` on doubles, MUFU beyond the existing RCP64H/RSQ64H seeds, F2F `.SAT` for doubles.

## Global memory follow-ups (`global-memory-2026-10-17.md`)
- `ATOM.CAS` (32-bit) on storage buffers (`0xeef0`): compare in Rb, new value in Rb+1. 64-bit CAS is logged as not implemented.
- Coherence: `BufferCache::markGpuModified(range)` is called when a draw/dispatch binds a written storage buffer. `BufferCache::get` for a range that intersects those intervals returns `Renderer::getGuestMemoryBuffer(range)` (a view of the live pages) instead of a CPU snapshot, so later vertex/uniform/index users read what the GPU wrote, in queue order. At most 256 intervals are kept. The texture cache is still not told about SSBO writes.

## Report semaphores (`ThreeD::setReportSemaphore`)
- Release with `REDUCTION_ENABLE` (bit 3): atomic ADD/MIN/MAX/INC/DEC/AND/OR/XOR of the payload into the first word (unsigned or signed, bits 9–11 and 17–18), no timestamp.
- Acquire: waits (polling, 50 µs) until the word equals or is at least (signed difference) the payload, bit 16 picks the comparison. The wait is capped at 1 s with a one-time warning so an unreleased semaphore cannot hang the GPU.
- `AWAKEN_ENABLE` (host interrupt) and `TRAP` stay no-ops. Other counters still report 0.

## G4R4 / RGB32
Upload expansion existed (`expandTexturePixels`: G4R4→RG8, RGB32→RGBA32 with alpha 1/1.0f) but had no test and no documentation; `testExpandedFormats` covers it. These formats are not render targets, so no readback is needed.

## Checked and left alone
- BRX "unbounded/unsupported target pattern" warnings in `hydra-shader-corpus-tests` come from the tool not providing `read_const_word`. In the game the bounded IMNMX→SHL→LDC→BRX pattern decodes; `testIndirectBranch` covers it.
- VADD/VABSDIFF/VSET/VSHL/VSHR: envytools has the encodings but not the saturation, `ud`/`sd` and scaling semantics, and Eden does not implement them. Not guessed.

## Deliberately not implemented
Each needs a design that Metal does not give natively; none is known to be used by Crash 4 or Jump Force.
- **Logic ops** (`SET_LOGIC_OP`): no fixed-function support. Would need framebuffer fetch (`[[color(n)]]`) in the fragment shader, with per-format bit packing, in the shader key and pipeline.
- **MSAA, alpha-to-coverage, sample shading**: multisample render targets in the texture cache plus resolves when sampled. Alpha-to-coverage is a pipeline flag but only matters with MSAA.
- **Transform feedback / DRAW_AUTO**: no stream-out; would be a compute emulation of the vertex stage.
- **Geometry and tessellation shaders**: no stages; would be compute emulation.
- **Exact sampler border colours**: Metal has three presets (transparent black, opaque black, opaque white); others would need border emulation in the shader keyed on sampler state.
- **Non-indexed primitive restart**: the hardware only restarts indexed draws.
